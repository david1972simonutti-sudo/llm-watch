North 2 : plateforme agents enterprise avec mémoire persistante et plafonds de dépenses
Cohere
2026-10-05
Outils & orchestration agentique
 Les déploiements agents en production forçaient les entreprises à sacrifier l'un des trois piliers : sécurité, capacité ou contrôle des coûts. North 2 introduit des quotas par utilisateur, des plafonds organisation, et une mémoire inter-sessions qui évite à chaque agent de redémarrer à zéro. Workflows agents mutualisés entre équipes (finance, juridique, RH) sans reconstruire la même logique ; automatisations planifiées multi-étapes avec validation humaine sur les points sensibles ; génération de slides/dashboards directement depuis une requête en langage naturel ; connecteurs Slack, GitHub, SharePoint/OneDrive + futurs connecteurs PitchBook, S&P Global, FactSet. Nouveaux contrôles de consommation (plafonds tokens par utilisateur et par groupe) permettant de maîtriser la facture agent à l'échelle organisation — tarification non publiée séparément, incluse dans la plateforme North. presse ↗
Embed 5 : modèles d'embedding frontier en deux tiers (Pro + Fast) pour la recherche enterprise
Cohere
2026-09-30
Augmentation & RAG
 Jusqu'ici, les équipes devaient choisir entre qualité de retrieval et coût/latence, et toute migration de tier obligeait à reconstruire l'index vectoriel. Embed 5 partage un espace d'embedding unique entre Pro et Fast : on indexe avec Pro (qualité maximale) et on interroge avec Fast (2,4× plus rapide, moins cher) sans réindexation.
Benchmark — Cohere annonce 85,8 sur ViDoRe V3 pour Embed 5 Pro (vs 83,7 Voyage 4 Large, 83,2 Gemini Embedding 2) et 83,4 sur parsed PDFs (vs 80,8 Gemini Embedding 2, 83,6 Voyage 4 Large). Scores issus d'évaluations internes Cohere sur 40 datasets de développement — pas d'audit tiers indépendant confirmé à ce jour ; risque de contamination non écarté sur les datasets internes.
 RAG sur documents financiers, PDFs complexes, images et contenu multilingue (100+ langues, contexte 128K tokens) ; search sémantique latency-sensitive à grande échelle (call centers, portails clients) ; pipelines agents qui réduisent le bruit avant d'appeler les modèles génératifs coûteux ; déploiement on-prem via Model Vault, Microsoft Foundry ou Amazon SageMaker. Pro : $0,12/M tokens texte — Fast : $0,08/M tokens texte — Images : $0,40/M tokens (les deux tiers). Réduction de stockage vectoriel jusqu'à 256× grâce au Matryoshka + quantization int8/binaire. Nouveau palier tarifaire Fast clairement moins cher que les offres concurrentes (Voyage 4 Large, Gemini Embedding 2). officiel ↗

Claude Code Mods — extensions TypeScript pour personnaliser l'agent de code
Anthropic / Claude
2026-10-01
Outils & orchestration agentique
 Impossible jusqu'ici de modifier le comportement interne de Claude Code (boucle agent, appels d'outils, permissions, UI) sans forker ou patcher le binaire.
